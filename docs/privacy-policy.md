# 隐私政策 — AssetPile｜材栈

**最后更新:2026-09-15**

AssetPile｜材栈("本应用")是一款本地优先的 Windows 下载文件整理工具。本政策说明本应用会访问、存储、传输哪些数据。

## 概要

- 本应用不收集、不存储、也不传输任何个人信息。
- 不需要也不支持注册账号或登录。
- 所有应用数据(被追踪的文件记录、标签、分组、操作历史、设置)只保存在你自己设备本地的 SQLite 数据库中(位于应用的本地数据目录,便携版则在可执行文件旁边的 `data` 文件夹),不会上传到任何地方。
- 本应用唯一的网络请求,是访问 GitHub 公开的 Releases API 来检查是否有新版本,详见下方"更新检查"。

## 本地文件访问

本应用会监视你选择的文件夹(默认是"下载"文件夹)以发现新下载的文件,并执行你主动发起的文件操作(移动、重命名、打标签、删除),这些操作全部在你自己的设备上进行。文件名、路径以及你打的标签只会记录在本应用的本地数据库里,不会离开你的设备。

## 更新检查(本应用唯一的联网行为)

当你打开应用的"设置"页面时(如果"自动检查更新"处于开启状态,这是默认设置),或者你点击"检查更新"按钮时,本应用会向以下地址发送一次不带身份认证信息的 HTTP GET 请求:

```
https://api.github.com/repos/RaiN5417/AssetPile/releases/latest
```

这个请求不包含你的姓名、文件名、文件内容、设备标识符或你设备上的任何其他信息——就是普通浏览器打开这个网页时会发出的同一种请求。GitHub 可能会按照其自身的隐私规范记录标准的网络请求信息(例如 IP 地址、访问时间);本应用自身除了从返回结果里读取一个版本号和一个发布页链接以外,不会访问、存储或处理任何其他数据。你可以在"设置"里完全关闭这项检查。

## 不使用分析、埋点或广告

本应用不包含任何数据分析 SDK、崩溃上报服务、埋点统计或广告。

## 第三方

本应用唯一会通信的第三方服务是 GitHub(用于上述的更新检查)。本应用不会向任何其他第三方分享任何信息。

## 儿童隐私

由于本应用完全不收集个人信息,因此也不会有意收集任何人(包括儿童)的信息。

## 数据保留与删除

所有应用数据都保存在你自己的设备上,由你自行掌控。卸载本应用不会自动删除本地数据库;你可以自行从应用的数据文件夹中删除,或使用应用设置中提供的清除选项(如有)。

## 政策变更

如果本政策有变更,更新后的版本会发布在同一个地址,并更新上方的"最后更新"日期。

## 联系方式

关于本政策或本应用的问题,可以在项目仓库提交 GitHub Issue:<https://github.com/RaiN5417/AssetPile/issues>

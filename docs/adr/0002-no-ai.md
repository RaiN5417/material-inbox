# ADR-002: No AI classification

**Decision:** human-in-the-loop only. The app never guesses which
project/group a file belongs to.

**Reason:** the user has the most accurate context for a file in the moment
right after they download it — the product problem isn't "guess better,"
it's "capture that context with minimum friction before it's forgotten."

**Avoids:** misclassification, privacy exposure from cloud inference, a
network/runtime dependency, and a whole category of complexity this project
doesn't need to take on.

# Security Policy

Download Inbox is local-first: no account, no cloud, no telemetry, no AI. See
[docs/security.md](docs/security.md) for what the local database holds and
how file operations are kept safe.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Instead, use
this repository's **Security → Report a vulnerability** (GitHub private
security advisory) so it can be triaged before details are public.

## Supported versions

Pre-1.0: only the latest released version is supported.
